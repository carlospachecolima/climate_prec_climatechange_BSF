# climate_prec_climatechange_BSF

Future precipitation projection maps (ACCESS-CM2, CMIP6) for the Baixo São Francisco region, Brazil, using automated processing and generative AI tools.

---

## 🌎 Climate Projections – ACCESS-CM2 (CMIP6) for Baixo São Francisco, Brazil

This repository contains future precipitation projection maps for the Baixo São Francisco region (Brazil), generated using the ACCESS-CM2 model from CMIP6 and automated through generative AI tools integrated with QGIS.

---

## 📍 Region of interest

- **Area**: Baixo São Francisco, Northeast Brazil  
- **Coordinates**: approx. -10.3° to -11.5° S, -36.5° to -37.8° W  

---

## 🔬 Methodology

- **Climate model**: ACCESS-CM2 (CMIP6)  
- **Variable**: Precipitation (mm)  
- **Scenarios**:  
  - SSP126  
  - SSP245  
  - SSP370  
  - SSP585  
- **Time periods**:  
  - Histórico: 1970–2000  
  - 2021–2040  
  - 2041–2060  
  - 2061–2080  
  - 2081–2100

- **Tools**:  
  - QGIS 3.36+  
  - Python automation scripts  
  - GitHub Copilot + ChatGPT for layout generation

---

## 📁 Folder contents

Each `.zip` file contains 12 monthly layout maps (January to December) in `.png` format and their corresponding `.qpt` layout files used in QGIS.

- `Layouts_prec_SSP126_2021 a 2040.zip`  
- `Layouts_prec_SSP245_2021 a 2040.zip`  
- ...  
- `Layouts_prec_histórica.zip`
